# Profile Website

Simple personal profile website built for Week 2/3 practice assignment.

Description
-----------
This project contains a small static personal site with a Home and About page, written using only HTML and CSS.

Folder structure
----------------
profile-website/
│── index.html
│── README.md
│── src/
│ ├── pages/
│ │ └── about.html
│ ├── css/
│ │ ├── style.css
│ │ └── about.css
│ └── assets/
│   └── profile.svg

Technologies
------------
- HTML
- CSS

Usage
-----
Open `index.html` in a browser to view the site. Update the placeholder name, email, phone, and the image in `src/assets` as needed.
